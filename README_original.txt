TalentBuzz Private website — Private client edition
==========================

Upload index.html, founder.html, privacy.html and headshot.png together into the web root for talentbuzz.net (often public_html).
All four files must sit in the same folder for the navigation, privacy links and founder portrait to work.
The site is a self-contained HTML/CSS/JavaScript page; no npm or build process is required.

The design loads two background photos from Unsplash and web fonts from Google Fonts.
These are external resources and require an internet connection. If your hosting
or privacy requirements call for locally hosted assets, replace those URLs.

IMPORTANT BEFORE GOING LIVE
---------------------------
The confidential consultation modal opens a prefilled email addressed to
private@talentbuzz.net. Visitors must send it through their own email app.
The site does not store or submit enquiries directly. If you want a form
that sends automatically, configure a secure form backend later.

This file package does not modify your domain DNS or email configuration.

The Meet Our Founder page uses Michelle's original uploaded headshot.png,
without altering the image file. The photo is visually fitted with CSS only.

The Privacy Policy reflects the current static website and email-based enquiry
process. Review the business identity, actual service procedures, retention
rules and third-party tools with qualified privacy counsel before relying on
it for broader international client operations. Update it when tools change.
